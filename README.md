# 淮海战役 · 三维地图课

在线预览：https://abcd9845.github.io/huaihai-3d/

以徐州为中心的淮海战役示意地图。可以连续播放全过程，也可以停在开局、碾庄、双堆集、陈官庄、结局五个章节；并能只看解放军、只看国民党军，或同时看双方。

本项目供个人学习使用。代码为本次编写，著作权归 Rui。史实取自公开记载，地图与部队位置为示意，不代表精确行军路线。请勿重新发布或改名冒充原作。

本地打开：把本仓库当作静态站点，在目录里执行 `python3 -m http.server 4173`，然后访问 http://127.0.0.1:4173/ 。

## 地理数据来源与许可

- 中国省界、南海九段线：阿里云 DataV.GeoAtlas（`100000_full.json`，数据来自高德开放平台），按其条款仅用于学习展示；已用 RDP 简化后内置在 `src/data/geo.json`。
- 河流（淮河、沂河、颍河、泉河、黄河、长江）、湖泊（洪泽湖、高邮湖、微山湖、骆马湖等）：Natural Earth 1:10m（公有领域）。
- 地形高程：Mapzen / Tilezen Terrain Tiles（AWS Open Data，Terrarium 格式，z8），重采样为 `public/data/dem.bin`（114.8–119.8°E，32.2–35.3°N，约 1.4 km 网格）。署名：SRTM、GMTED2010 等，courtesy of the U.S. Geological Survey（见 tilezen/joerd attribution）。垂直方向有夸大。
- 城镇坐标（徐州、碾庄圩、双堆集、陈官庄、青龙集等）：维基百科与国家地名信息库公开坐标。
- 废黄河故道、运河与津浦、陇海铁路：按真实城镇、车站坐标手工描线，为示意。
- 字体：思源宋体、思源黑体（Noto Serif/Sans SC，SIL OFL 1.1），按本页用字裁剪。

## 部队兵种图标的依据

图标按北约军标简化：步兵为 X，装甲为椭圆，炮兵为圆点，骑兵为单斜线，指挥部为旗杆；红色为解放军，蓝色为国民党军。

- 有出处的主力构成：
  - 第12兵团（黄维）：第10、14、18、85军及第4快速纵队，有坦克、装甲车与105毫米榴弹炮，美械为主（央视网《淮海战役双堆集地区歼灭战》、百度百科「第十二兵团」、维基百科「快速纵队」）。
  - 第2兵团（邱清泉）：以第5军（抗战时第一支机械化部队）为骨干，配属坦克，突围时仍有坦克随行（凤凰网历史、人民政协网《解放军骑兵追歼敌人坦克》）。
  - 华东野战军：以步兵为主，另有特种兵纵队（炮兵、坦克大队、骑兵团）（央视网、人民网党史、人民政协网）。
- 没有找到可靠构成说明的，一律标「步兵为主」：第7兵团、第13兵团、第16兵团、中原野战军，以及各路解放军部队。杜聿明标为指挥部。
- 解放军只按方向（东路、北路、南路、阻援）和野战军标注，不写纵队番号。
